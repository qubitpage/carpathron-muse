SSH keys

          

        
Keys made here are stored encrypted in the app. Use Install on server to add a key to a server's authorized_keys and switch that server to key login (safer than passwords). Keys from %USERPROFILE%\.ssh are listed too.

        

      


      
      

        
🛡 Carpathron Shield

        
Security for what you build and where you publish it: secrets in code before publishing, server hardening, website checks and live monitoring. Fixes are backed up, and firewall/SSH fixes undo themselves if the app cannot log in again. Only scan projects, servers and sites you own or manage.

        

        

        
Live monitoring

        
Checks run from this PC over SSH while the app is open: new open ports, password-guessing bursts, new logins, full disk, high load, server down, and /.env or /.git exposed on your sites. Nothing is installed on the server.

Camera

            
With the Carpathron firmware the car's own camera is used automatically. Optional: another snapshot URL (phone IP-camera app). Otherwise this device's camera is used.

            

            
            
            
            

          

          

          

          

            
Robot head & room map

            
The camera is fixed to the car, so the car turns its body to look (like a robot), takes the photo and turns back. A room scan turns a full circle, photographs every side and draws a map.

            

              
            

            
            

            
            
Turn calibration
              
Time for one full circle at turn speed. Press Test 360°: the car should end facing exactly where it started. Turned too far → lower the time; not far enough → raise it.
